Damast

Every commit a layer.

A soft fork of Forgejo, folded once more. Same data, same config, a few extra features. And a way back, any time.

What's different

FeatureForgejoDamast
Co-authored-by trailersPlain text in the messageCo-authors shown and credited on commits
Package registryOwned by user/org, optionally linked to a repoBound to the repository: repo write publishes, repo read downloads
Everything elseIdentical. Damast follows every Forgejo release.

Drop-in, both ways

Damast vX.Y.Z-damast.N is built on Forgejo vX.Y.Z. Switch by swapping the binary or image. To go back, start Forgejo of the same version on the same data. Damast never touches Forgejo's database schema. Its extras live in separate damast_* tables.

CLI

mast is the companion CLI. It works with Damast and with plain Forgejo.
